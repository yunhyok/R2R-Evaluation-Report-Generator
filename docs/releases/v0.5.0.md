여러 라벨 데이터셋(전기 측정, ML 예측, 육안·VLM 광학 라벨)을 한 리포트에서 비교할 수 있는 단계형 워크플로 릴리스입니다.

## 새 기능
- **5단계 위저드**가 기본 화면입니다: 데이터셋 → 라벨 체계 → 비교 정의 → 출력 옵션 → 생성. 이전 단계를 고치면 이후 단계는 무효화됩니다. v0.4 두-입력 화면은 `--legacy-ui`로 엽니다.
- **입력**: R2R-TXT-Converter 측정, R2R-Machine-Learning 예측, ImageMarker 2.x 라벨(`Status` 덮어쓰기 xlsx 또는 `name,row,node,label` CSV), Printed-Device-AI-Inspector long/matrix CSV(`image_path`, 모델 열 선택). 격자는 데이터셋 속성(기본 26×38)입니다.
- **라벨 체계 레지스트리** `label_schemes.json`: 구 체계(Pass/No Active/None/Open/Short/No Gate Effect)와 신 전기 체계(E-Normal/E-NoActive/E-Open/E-Short/E-Invalid), ML 3-class, 광학 GOOD/BAD/OPEN, 이진을 기본 제공하며 `%APPDATA%\R2R Evaluation Report Generator\label_schemes.json`으로 추가·덮어쓸 수 있습니다. 체계 밖 라벨은 진행을 막습니다.
- **비교는 선택·생략 가능**
  - 자기 평가(A가 정답): confusion matrix, 정확도(Wilson CI), macro/weighted F1, 클래스별 지표, Cohen κ, MCC, 다수 클래스 기준선.
  - 교차 연관(어느 쪽도 정답 아님): 교차표(건수·행%·열%·기대빈도), χ², Cramér's V(Bergsma 보정), Haberman 조정 잔차, Theil's U, 관심 2×2 셀별 odds ratio(Woolf CI)·RR·φ·Yule's Q·Fisher p·Holm p, 공통 범주일 때 κ와 PA/NA.
- **새 workbook 구성**: README(프로파일 JSON 내장) → Label_Audit → Alignment → Joined_Data → 샘플별 공간 map(S01…: 데이터셋별 raw map, agreement map, co-occurrence map) → 비교별 시트(C01…) → Overall Summary. 코드 포함본과 `-color-only.xlsx`를 함께 생성합니다.
- **재현성**: 출력 옆에 `<stem>.profile.json`이 저장되며 `R2REvaluationReportGenerator.exe --profile FILE [--output X]`로 같은 리포트를 다시 만듭니다.

## 호환성
- v0.4까지의 측정·예측 두-입력 리포트는 legacy 프리셋으로 같은 지표가 나오며(회귀 테스트), `--legacy-ui`에서는 기존 레이아웃 그대로 생성됩니다.
- 의존성에 numpy·scipy가 추가되어 설치 파일 크기가 커졌습니다.

## 검증
- 자동 테스트 74건, ruff, `--self-test`(profile 리포트 포함), GUI 스모크(offscreen), Windows CI(PyInstaller 빌드·실행파일 self-test) 통과.
- 별도 리뷰에서 발견된 결함 8건(와일드카드 매핑, 라벨 대소문자 변형, 범주 밖 카테고리, 2×2 셀 라벨 검증, 중복 정렬, 0 마진 표기 등) 수정 및 회귀 테스트 추가.
- 지표 정의와 참고문헌: `docs/METHODOLOGY.md` "Profile reports" 절.
