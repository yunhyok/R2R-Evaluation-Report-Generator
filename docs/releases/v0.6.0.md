Local LLM을 독립 비교군으로 다루고, v0.5.1 GUI에서 검사가 진행되지 않던 문제를 고친 릴리스입니다.

## 변경
- **Local LLM 비교군**: 데이터셋 역할에 `optical_vlm_local`("광학 Local LLM 라벨")을 추가했습니다. Printed-Device-AI-Inspector 내보내기에서 `lmstudio:`(및 `ollama:`, `llamacpp:`, `vllm:`, `local:`) 모델 열을 고르면 자동으로 이 비교군이 제안되고, 그 외 공급자는 "광학 VLM 라벨 (cloud API)"로 제안됩니다. 같은 내보내기를 모델별로 여러 번 추가해 cloud 모델과 Local LLM 모델을 각각의 비교군으로 둘 수 있으며, 기본 제목이 `<파일명> [provider:model_id]`로 붙어 구분됩니다. 모델 열을 바꾸면 비교군과 (수정하지 않은) 기본 제목이 따라 바뀝니다.
- **리포트 표기**: README 시트에 *Comparison group*·*Role key*·*Provider*(`lmstudio (local)` / `gemini (cloud)`) 열이 추가되고, Overall Summary에 *Comparison groups (dataset roles)* 표(비교군·데이터셋·공급자·모델·체계·샘플 수·라벨 수)와 Local LLM 비교군 주석이 들어갑니다. 지표는 cloud VLM과 동일하게 계산합니다(METHODOLOGY "Comparison groups and the Local LLM group").
- **수정 — GUI 검사가 2단계로 넘어가지 않음(v0.5.1)**: '불러오기·정렬 검사'가 샘플 블록 검사 뒤 파일 읽기 단계를 시작하지 못하고 `이전 작업이 끝나기를 기다리세요.`에서 멈추던 문제. 작업 결과를 작업 스레드가 해제된 뒤에 전달하도록 바꿨습니다. 실제 스레드 모드 회귀 테스트를 추가했습니다(기존 테스트는 동기 모드만 검사했음).
- **수정 — Inspector 모델 열 유실**: 검사 중 화면이 비활성화되면 모델 열이 None으로 읽혀 "choose the Inspector model column" 오류가 나던 문제.
- 동기 모드에서 중첩 작업의 실패 메시지가 "완료했습니다."로 덮이던 표시 문제 수정.
