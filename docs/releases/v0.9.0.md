샘플별 공간 map 시트에 측정 *그 자체* — 각 소자의 transfer curve — 를 26 × 38 격자로 함께 그리고, 프로그램 아이콘을 추가한 릴리스입니다.

## 변경
- **측정 transfer curve 격자**: 데이터셋이 R2R-TXT-Converter 내보내기(`_merged.csv`의 전압값 헤더 전류 열, `_raw.csv`의 `I_<전압>V` 열, 또는 같은 표의 `.xlsx`)이면 파서가 각 소자의 게이트 sweep을 그대로 보존하고, 샘플 시트(S01…)에서 그 데이터셋의 라벨 map 바로 아래에 소자별 `log10|I|`–`V` 곡선을 26 × 38 칸에 그린 그림 한 장을 넣습니다. 곡선 색은 그 데이터셋의 라벨 색이며, 축은 샘플 전체가 공유합니다(x: 전압 최소→최대, y: `1e-13 A`부터 샘플 최대 전류 자릿수까지 로그). sweep이 없거나 숫자가 아닌 좌표는 회색 칸입니다. 이제까지는 판정 결과(라벨) map만 나열되고 측정값 자체는 리포트에 없었습니다.
- 같은 sweep을 가진 데이터셋(측정 workbook에 육안 라벨을 덮어쓴 ImageMarker 사본 등)은 한 번만 그립니다. 전압 열이 없는 데이터셋·기존 리포트는 달라지지 않습니다. 색상 전용 사본에도 같은 그림이 들어갑니다.
- 4단계 출력 옵션에 **map 시트에 측정 transfer curve 격자 포함** 확인란(프로파일 `options.sweep_maps`, 기본 켜짐, 공간 map을 끄면 함께 비활성)이 추가되었고, README 시트의 *Measurement sweep maps* 행에 삽입된 격자 수가 기록되어 재개방 검증이 실제 그림 수와 대조합니다. 셀프테스트(`--self-test`)의 합성 측정 파일에도 전압 열이 들어가 패키징된 EXE에서 그림 생성까지 검증합니다.
- **프로그램 아이콘**: 창 제목 표시줄·작업 표시줄·EXE·설치 프로그램에 같은 아이콘(리포트 페이지 위의 26 × 38 라벨 map과 판정 체크 배지)이 쓰입니다. 원본은 `assets/icon.svg`, 재생성은 `python scripts/build_icon.py`. Windows 작업 표시줄 그룹도 python.exe가 아닌 이 앱으로 묶입니다.
- 새 의존성 `Pillow==12.3.0`(격자 렌더링과 openpyxl 이미지 삽입).

## 참고
- 리포트 크기는 샘플당 그림 한 장(약 1250 × 650 px, 수십 KB)만큼 커집니다. 비교 지표·라벨 집계·Joined_Data는 sweep을 읽지 않으므로 변하지 않습니다.
- ``.xlsx`` 측정 입력은 헤더 셀이 숫자여도 전압으로 읽습니다.
