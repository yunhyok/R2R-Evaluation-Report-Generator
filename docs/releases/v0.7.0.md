R2R-Machine-Learning 0.6.0의 육안 라벨(Good / Bad / Open) 학습 모델이 내보낸 prediction set을 읽고, 독립 비교군으로 평가하는 릴리스입니다.

## 변경
- **Good / Bad / Open prediction set 지원**: R2R-Machine-Learning `visual_3class` 모델의 `predictions.csv`(`prob_Good`, `prob_Bad`, `prob_Open` 열)를 그대로 불러옵니다. v0.6.0까지는 `prob_Open` 열이 전기 모델의 별칭에 걸려 "prob_Normal, prob_Open, and prob_Short must be supplied together" 오류로 파일을 읽을 수 없었습니다. 확률 열은 이제 `prob_<class>` 형태를 클래스 집합과 무관하게 읽으며, 같은 계약(함께 제공, 0~1, 합 1 ± 1e-5)을 검사합니다. 전기 모델의 `prob_Normal / prob_Open / prob_Short`는 기존과 동일하게 처리됩니다.
- **새 비교군 `optical_ml` — "광학 ML 예측 (Good/Bad/Open 육안 라벨 학습)"**: 육안 라벨로 학습한 ML 모델의 예측을 전기 ML 예측(`electrical_ml`)과 구분하는 비교군입니다. 예측 라벨은 육안·VLM 라벨과 같은 `optical_3` 체계(GOOD / BAD / OPEN)에 속하므로, 육안(또는 VLM) 라벨을 정답으로 두는 *자기 평가*(confusion matrix·F1·κ·MCC)와 전기 측정과의 *교차 연관*(χ²·Cramér's V·odds ratio)을 그대로 정의할 수 있습니다. `optical_to_binary`, `optical_to_3class` 프리셋도 그대로 적용됩니다.
- **비교군 자동 제안**: R2R-Machine-Learning 예측 파일을 추가하면 `prob_<class>` 열의 클래스 집합으로 학습 체계를 식별해 비교군을 미리 고릅니다 — `Good / Bad / Open`이면 광학 ML 예측, `Normal / Open / Short` 또는 E-5 라벨이면 전기 ML 예측. 사용자 정의 체계는 제안하지 않습니다(직접 선택).
- **라벨 철자 통일**: 체계가 지정된 데이터셋의 라벨은 대소문자·공백을 무시해 체계의 철자로 표기·비교됩니다(ML의 `Good` → `GOOD`). 이전에는 육안 `GOOD`과 ML `Good`을 identity 매핑으로 자기 평가하면 오류 없이 6범주 행렬(정확도 0)이 만들어졌습니다. 비교 정의 안에서 대소문자만 다른 범주 대상도 하나의 범주로 합쳐집니다(먼저 선언된 철자 우선). `Label_Audit` 시트에 *Observed spellings* 열이 추가되어 원본 파일의 철자를 함께 기록합니다.
- **리포트 표기**: README 시트의 *Comparison group* / *Role key*에 `optical_ml`이 나오고, Overall Summary의 *Comparison groups (dataset roles)* 표 아래에 광학 ML 비교군 주석이 들어갑니다. 셀프테스트(`--self-test`)가 Good / Bad / Open 예측 데이터셋과 두 비교(운영 binary 자기 평가, 원본 상태 교차 연관)를 추가로 생성·검증합니다.
