v0.5.0 워크플로를 실제 병합 CSV와 Inspector Excel 내보내기에 맞춘 수정 릴리스입니다.

## 변경
- **이름이 반복되는 샘플·불완전한 어레이 처리**: R2R-TXT-Converter 병합 CSV처럼 같은 이름이 여러 블록으로 나오거나(재측정, 시트 중복) 988개 미만인 블록이 있으면 파일을 거부하지 않고 **샘플 블록 선택 창**을 엽니다. 블록별로 포함 여부와 샘플 이름을 정할 수 있고, 내용이 완전히 같은 블록은 '동일 내용'으로 표시되며, 불완전한 블록은 포함할 수 없습니다. 선택은 프로파일 JSON(`datasets[].samples`)에 저장되어 `--profile` 재실행 시 그대로 적용됩니다.
- **Inspector Excel 내보내기 지원**: `Run / Results / Matrix / Attempts` 시트 구조의 `.xlsx`를 바로 읽습니다(Matrix 우선). 모델 열은 `provider:model_id`로 선택합니다.
- **판정 없는 좌표**: LLM 호출 실패 등으로 verdict가 없는 소자는 예약 라벨 `(missing)`으로 유지되어 어레이가 완전한 상태로 남습니다. 모든 체계에서 허용되고, 모든 비교에서 제외(집계됨)되며, map에는 회색으로 표시됩니다.
- 기준 데이터셋 중 짝이 없는 샘플도 리포트에 남습니다(공간 map만).
- 70개 샘플 리포트가 10분 이상 걸리던 성능 문제 수정(라벨 정규화 캐시) — 현재 코드 포함·색상 전용 두 파일 생성에 약 30초.

## 검증
- 자동 테스트 80건, ruff, `--self-test`, Windows CI(빌드·설치 실행파일 self-test) 통과.
- 실제 20260731 병합 CSV(72,250행, 62개 이름 중 반복 10개·불완전 5블록)와 Inspector gemini 내보내기(4,940 이미지)로 정렬·교차 연관 리포트 생성 확인.
